# 現行コードの所有

現在の構造は[repository layout](../architecture/repository-layout.md)、実行入口は[ops](../../ops/README.md)を正本とします。この文書に別のtree・版数・ファイル数を複製しません。

記事と分類/媒体/公開来歴はcontent、画面はapps、共有契約と純粋処理はpackages、実行とprovider IOはopsです。source-inputsの原画像、選択vendor、公開fontは現役の入力であり、旧移行コードと一緒に削除しません。

削除前のコードや当時の手順は[固定Git履歴](source-history.md)で参照できます。過去の移行台帳を現行CIの正本として再生成しません。
