# ADR-0034: 編集的なタイポグラフィと作業写真を中心にしたホーム

## 状態と適用範囲

ユーザーが視覚比較を通じて選択したブランド、字体、ホーム構成を記録する。採用対象はfrontendの見た目と導線であり、Astro / Tailwind 4、必要な箇所だけのReact island、静的本文、既存ルート・metadata・検索・migration・securityの契約は変更しない。

本記録のacceptedは視覚方針の採用を表す。PR candidateの実装、mainへのmerge、本番での有効化は別の状態である。メディアの権利確認・登録・保存・公開・保護・復旧、保留記事の公開、provider変更やdeployを許可する記録ではない。

## 背景

サイトを、一般的なAI SaaS風の装飾、反復するカード、抽象的な宣伝文から、技術とものづくりの内容が伝わる個人サイトへ刷新する。Xpotatoという名前は、ドメインとリポジトリの継続性を保つため固定する。

最初は制作物を大きく見せるOpen Workshop構成を試した。その後、ロゴ・紹介・実写真を主役にする方向を比較し、紹介文と写真の左右配置を選択した。ただし写真が独立したカードのように見えたため、全幅の作業写真へ文字を重ねる案へ進んだ。

選択肢の言語説明だけでは配置や字体の違いを判断しにくかった。比較できる実画像を示し、決定後は画像の文字を貼り付けず、実フォントと元のロゴ・写真を使って実装する。

## 採用する方針

### ブランドとロゴ

- 名前はXpotato。文字ロゴは**Xpotato.net**とし、`.net`は小さめの補助表記。
- アクセントは紫を基準とする。値の正本はCSSの`--accent`（採用時点は`#745399`）。余白、罫線、文字の階層を中心にし、過度な装飾やカードの多用を避ける。
- 幾何学的なXPの輪郭を精密化した現行SVGを採用する。明るいX／右側のPと、奥に見える濃い横帯を組み合わせる。
- 一本の物理的なリボンで製作可能であることを証明したロゴ、という主張はしない。今回ロゴを再設計しない。
- SVGは`apps/site/public/xpotato-logo.svg`、文字部分はHTMLで扱う。

### キャッチフレーズと字体

**Think. Build. Run.**は、考える・作る・動かすを短い動詞で表す。3語は同じサイズ・ウェイトで同格に扱う。

大きな英語見出しはNoto Serif、日本語大見出しはNoto Serif JP、本文・メニュー・小見出しはZen Kaku Gothic New。本文をセリフ体に変更せず、コードは別の等幅書体の役割を保つ。

公式OFLを保持したWOFF2を同一originで配信する。必要なウェイトに限定し、Unicode分割と`font-display: swap`で必要な文字だけを読み込み、fallbackでも読めるようにする。ビルドや閲覧時に外部フォントサービスへ依存しない。取得元とライセンスは`apps/site/public/fonts/`、字体の定義は`apps/site/src/styles/fonts.css`に記録する。

### 全幅写真と2行の見出し

旧トップで使われた工作台の元JPEGを選ぶ。生成モックアップ中の写真を元写真の代用にしない。

- 旧実装の基準: `legacy-pre-vnext-2026-08-28` / `927d105713561309fc5e2374396f86646b5aeb2a`。
- 元資産: `public/images/ui/hero-workshop-stage.jpg`、2400×1350。
- 元の公開パス: `/images/ui/hero-workshop-stage.jpg`。2026-10-04の確認時点では404であり、現在のトップはvNext foundation。
- 旧トップのCSS `.hero-stage`による参照を確認。旧実装に存在することだけで、撮影者の帰属や現行の再公開ゲート完了を推定しない。

写真は全幅で背景の役割を持たせ、上に紹介を組む。CSSで彩度を抑え、暗いニュートラルな重ねを使って文字を可読にする。白く濁らせず、工具の質感を残す。具体値はCSSを正本とし、元JPEG自体の色を変更しない。

2行／3行を比較し、写真が見える面積と縦の余裕を理由に、**一旦2行**を採用する。

```text
Think. Build.
Run.
```

PC・スマホでこの語順と改行を維持する。狭い画面で読めなくなる場合は、同格性を保ってサイズを調整し、改行変更が必要なら別途レビューする。背景のトリミングは画面幅に合わせて変え、文字やナビゲーションを画像化しない。

### 共通導線とホームの内容

- 控えめな高さのsticky帯にXP＋Xpotato.net。PCは**Blog / 制作物 / ツール / About / 検索**の順。
- スマホはロゴ / 検索 / メニュー。標準の開閉要素で主要項目と補助のNotesを辿れるようにする。
- Notesのルートは維持し、ホームの記事・ノート欄、スマホメニュー、フッターに補助導線を置く。ロゴがホーム導線を兼ねるため、Home項目を重ねない。
- 最初の画面にキャッチフレーズ、短い紹介、作業写真、About・制作物への導線。
- 下に実在する制作物、公開記事／ノート、プロフィールへの導線。Blogは主要な記事公開経路、Projectsは制作物の説明、Toolsは操作する場所、Notesは参照用資料として区別する。
- 公開記事が0件なら小さな空状態を表示し、保留記事で埋め合わせない。人物経歴・成果・記事・実測結果を創作しない。

カルーセル等のfrontend表現は積極的に使ってよい。実内容が複数ある制作物では、手動送り・スワイプ・キーボード操作を利用する。本文ページへの実行JavaScript禁止契約を維持し、CSSスナップスクロールと通常の番号リンクで実装する。読みを妨げる自動再生、1枚の写真を複製したカルーセルは設けない。focus、sticky帯による隠れ、`prefers-reduced-motion`を確認する。

## 見送った案と理由

| 比較した案 | 現在の判断 |
| --- | --- |
| 制作物を最初の画面の主役にする案 | ホームの入口は紹介と写真へ変更。制作物は下に残す。 |
| 紹介文と独立した写真を左右に配置する案 | 写真がカード的に見えたため全幅の背景へ変更。 |
| 大見出しもサンセリフに統一する案 | 見出しの個性と本文との役割分担からセリフ案を採用。 |
| 3語を3行にする案 | 写真の面積と縦の余裕から、現時点では2行を選択。 |
| Latoを本文に使う案 | 採用していない。日本語本文の比較でZen Kaku Gothic Newを選択。 |

これらは比較経過であり、将来の検討を禁止する制約ではない。以前の「カルーセル不要」という案も、現在のユーザー方針には適用しない。

## 暫定事項と今後の課題

- 2行は現時点の選択。実画面での読みにくさ等が判明した場合は再比較する。
- 紹介文「ロボティクス、プログラミング、日々の試行錯誤。」は暫定。Aboutは現在サイト方針の説明であり、確認済みのプロフィール情報を後から整える。
- コード書体は役割のみ分離。JetBrains Monoは未選定であり、既存の等幅fallbackを保持する。
- 写真の現行Media Registry登録・canonical source/public delivery/protected recoveryへの保存・公開は未完了。PRのローカルレビュー画像と本番公開を分ける。
- 実装時点では写真をGitへ追加しない。ローカルだけの`SITE_PREVIEW_WORKSHOP=1`と専用tempの写真で表示を確認し、通常buildからレビュー用パスとJPEGが除外されることを検査する。本番では暗いニュートラルな背景で同じ文字・構成を表示し、メディアゲート完了後に承認済みregistry bindingへ接続する。
- 44件の記事hold、検索／metadata／security、productionの権限・merge／deployゲートは維持する。

## 検証と正本

受け入れ条件は、PC・390px・320pxでの2行と3語の同格性、元写真とロゴの使用、実フォントの読み込み、文字の可読性、横はみ出しがないこと、sticky帯と本文スキップ、メニュー・制作物・戻る操作、動きを減らす設定への対応。既存のrepository/static・型・Astro・test・検索／ツール操作チェックも維持する。

具体値と実装の正本は`apps/site/src/styles/global.css`、`fonts.css`、`layouts/BaseLayout.astro`、`pages/index.astro`、機械可読の`lib/site-config.ts`。このADRは判断理由を記録し、CSSやnavigation registryを第二の設定表として複製しない。
