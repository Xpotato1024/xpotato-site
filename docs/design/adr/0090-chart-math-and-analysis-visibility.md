# ADR-0090: 数式表示と解析情報の公開粒度

## 背景

近似式、正規化座標、丸め前の係数を同一の二段組みで表示すると、スマートフォンでは折り返しや長い数値が説明の妨げになる。一方、計算の再現性を確保するため、詳細を削除せず切り替え可能にする。

## 判断

- 保存する測定点・理論式・近似条件・表示設定を分離する。
- `analysisDisplay` は `concise`（既定）・`detailed`・`hidden` の三状態。非表示でもグラフの曲線・データ表・元の計算は維持する。
- `concise` は折りたたみ内にTeXから生成した静的MathMLとR²・RMSEのみ表示する。`detailed` はさらに入れ子の折りたたみに正規化座標、丸め前の係数、点数・範囲・注記を追加する。
- TeXは検証済みの数値および限定式ASTから生成し、任意の著者入力TeXを処理しない。公開記事に追加のJavaScriptやWebフォントを必要としない。
- 小さい画面では数式のみ横スクロールし、計算情報は縦積みとする。長い数値は無理に折り返さない。

## 検証

正しい数式変換と演算子優先順位、静的MathML、三つの表示モード、rawデータと解析の不変性、MDXとプレビューの一致、スマートフォン幅での表示、全CIの成功を確認する。
