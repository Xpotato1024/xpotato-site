# ADR-0087: CMSから編集する比較条件と静的グラフ

## 背景

従来のComparisonは2つのラベルと共通本文しか持たず、条件ごとの本文・画像を扱えなかった。サイトにはVega-Liteによる図版制作CLIがあるが、CMSで数値を直して即時表示する入口がない。部品名だけのパレット照合では、DiagnosticItemの補足本文のような編集機能の漏れも検出できなかった。

## 実装候補

Comparisonの子を名前付きComparisonCaseとし、各条件をまとめて追加・編集・移動する。旧leftLabel/rightLabel形式はそのまま保持し、共通本文を推測で分割しない。

折れ線・散布図はLineChartのseries属性へ数値データを保持する。スキーマはcontent-contracts、静的SVGと表の描画はportable-content、見た目はサイトのcontent CSSが所有する。Astro・編集画面・即時プレビューは同じrendererを呼び、三重実装を避ける。公開ページへJavaScriptは追加しない。系列の色は共有tokenを使い、形と線種も変えて区別する。

6系列、各500点、絶対値1兆以下とする。既存制作CLIの有限値・値域と同じ条件を採用し、複数系列には固定の6種類の形と線種を割り当てる。散布図には折れ線用の昇順制約を掛けない。元の値と図の目盛りは区別し、データ表の値を表示都合で丸めない。

## 代案

- 比較のラベルだけを増やしても本文の所属は保存できない。
- 任意のVega-Lite仕様をブラウザで実行すると、既存の許可subsetを超えたAPIと大きなruntimeをCMSへ持ち込む。今回の折れ線・散布図の操作には必要ない。
- グラフを画像に固定すると数値の再編集が別工程になる。数値を頻繁に直す図はLineChart、複雑な図版制作は既存CLIとFigure経路を維持する。
- 全モジュールを同一の汎用フォームだけで済ませず、系列・比較条件など意味のある入力には専用操作を用意する。

## 確認と境界

正しい親への追加、属性・子本文の変更、無変更の原文保持、保存・再読込、静的Astroとプレビュー、モバイルの操作を確認する。未知の図式や脚注の視覚編集を対応済みと呼ばない。実装と試験はfeature PRに記録し、このADRをmain採用・本番配信・人による公開承認の代用にしない。
