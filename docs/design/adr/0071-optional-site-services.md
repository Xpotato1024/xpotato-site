# ADR-0071: 問い合わせ・解析・コメントをコア機能の依存にしない

## 背景

本人は問い合わせフォーム、プライバシー説明、解析、コメントとspam対策の検討・実装を進めることを求め、PWAのオフライン画面ではコメントが不要であること、付加機能を新しい必須依存にしないことを明示した。

## 候補

静的本文とブラウザ内Tool/PWAを維持し、受付は専用Workerへ分離する。Turnstile Managedと頻度制限を受付にだけ使用する。一般ページのWeb Analyticsは候補、コメント方式は未決。全てdefault-offとし、未設定時に通信やUIを発生させない。

現在の実装範囲は説明ページ・受付コアと合成試験・無効状態の配布物検査。画面や第三者連携を作っただけで送信/保存/公開条件を満たした扱いにしない。詳細と有効化条件は[任意サービスの設計](../../architecture/optional-site-services.md)を正とする。

## 結果と残る判断

Toolの通信禁止、PWA cache closure、static-first、依存package数を維持できる。一方、フォームの一般公開には配送・保存方針とprovider設定、UIと実受信試験が必要。解析とコメントはprovider/公開範囲/運用の確認後、対象routeだけの差分で実装する。本番公開・外部設定・Ready化・mergeはこの候補の承認に含めない。
