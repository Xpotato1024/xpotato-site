# ADR-0089: 理論式からの曲線と軸の範囲・余白

## 背景

測定値からの近似に加え、既知の理論式を先に描き、後から測定値と比較したい。計算済みの点列だけを取り込む方法では、係数や範囲を変えるたびに外部で点列を作り直す必要がある。また、データの最小値・最大値をそのまま軸の端にすると、端の点が軸と重なり、比較のために表示範囲を揃える操作もできない。

## 判断候補

1. LineChartの同じ系列配列に`role=formula`を追加し、式・X範囲・初期描画密度を保存する。測定値、外部の計算済み点列、近似曲線と区別し、理論式だけでも描ける。
2. 数式専用の小さい文法を解釈する。数値・変数x・定数・基本演算と限定した関数だけを受け付け、JavaScriptの実行や任意のVega仕様を開放しない。構文長、入れ子、評価回数、点数を制限する。
3. 不成立の点を黙って落としたり、極を線で跨いだりしない。定義域と描画区間を確認し、所定の上限内で表現できなければ式・範囲を直せるエラーを返す。式そのものの完全な解析や任意関数の全区間誤差保証は提供しない。
4. 軸は標準で各端に5%の余白を持つ。横軸・縦軸ごとに余白率を変更でき、最小値・最大値も各端を独立して固定できる。固定した端へ余白を足さない。
5. 表示範囲と解析対象を分ける。狭い範囲へ切り替えても全測定値・式を保持し、近似は元の全点を使う。図では範囲外を切り、範囲外の値があることを知らせ、データ表で全値を確認できる。
6. 既存の共通rendererを拡張し、CMSと公開Astroで同じ結果を使う。公開記事へ数式計算用のJavaScriptを追加しない。

## 代案と範囲

理論式を読み込んだ瞬間に点列へ置き換えると、後から式を直せないため採用しない。新しい汎用グラフ製品やCASの導入も、今回必要な1変数の理論式と表示調整には不要である。任意パラメーターの自動推定、信頼区間、誤差棒、対数軸は別の契約を必要とする。

初期の[ADR-0088](0088-experimental-charts-and-csv.md)は理論曲線の入口を外部の計算済みXYに限定していた。本候補はその入口を限定文法の式へ追加するもので、近似モデルの種類・目的関数・観測範囲外へ延長しない方針を変えない。

## 検証と採用

既知式、演算の優先順位、注入文字列、構文・計算の上限、定義域・極・微小値・大きいオフセット、系列の役割を単体で確認する。軸は5%・0%・片側固定・全同値・近接値・狭い表示範囲と、データ保全を確認する。CMSでは式だけの作成、後からのCSV追加、入力エラーからの回復、保存・再読込、自動へ戻す操作、モバイル幅を確認する。

入力と描画の正本は[CMS契約](../../contracts/cms-workbench-contract.md#理論式から作る曲線)。実装・CI・非公開プレビューの対象revisionと、mainへの採用・本番配信は区別する。
