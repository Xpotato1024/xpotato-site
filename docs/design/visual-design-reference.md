## 視覚上の個性と見出しの主従

温かい明色の背景、控えめな紫、罫線と余白、英語と日本語のセリフ見出し、読みやすいサンセリフ本文を組み合わせます。全要素を同じ書体・大きさ・カード形へ揃える整理ではありません。

- ブランドは幾何学的なXPロゴと `Xpotato.net` の文字です。[SVG](../../apps/site/public/xpotato-logo.svg)を別解釈で描き直しません。文字ロゴのsystem sansと小さい `.net` は本文・見出しとは別の意図的な表現です。
- ページの大見出し・節見出しは日本語display、ホームの英語スローガンは英語display、本文と操作文字はbody、コードはmonoの役割を使います。実フォントの所有は [fonts.css](../../apps/site/src/styles/fonts.css) と関連font定義です。
- h2/h3の意味上の階層を、文字サイズを揃えるために変更しません。`ArticleCard.astro` は一覧ではh2、ホームではh3を受け取り、ホームでは明示的な `titleRole="content-item"` を渡し、記事・制作物・ツール・更新題名を同じサンセリフの役割で描きます。一覧は既定の `archive` 役割を保持します。制作物カードや固定ページ一覧のsans見出しも、ページ見出しに従属する役割です。
- 本文のh2装飾は本文直下と明示的な `.content-h2` が対象です。部品内の見出しへ無差別に広げず、問い合わせの主領域と補助領域にも主従を残します。独立toolの `data-bt` 内部へ本文見出し規則を漏らしません。
- 日付・来歴・補足は主本文より控えめにします。折りたたみの操作文字を読みやすくする変更と、補足本文を大きくする変更は別です。

## 役割で揃える範囲

### 折りたたみ

サイト所有の折りたたみ操作には共通クラス `.disclosure-summary` と操作文字用トークンを使います。記事の補足、タグ発見、問い合わせfallback、tool説明で、同じ開閉操作の文字を個別に縮小しません。本文の補足・来歴・注記はそれぞれの小さい文字を維持します。

ヘッダーのメニューsummaryはアイコンによるナビゲーション操作なので、この本文向け規則に混ぜません。固定toolの内部summaryもvendorへクラスを手書きせず、hostの公開CSS変数で接続します。対象一覧と例外は[役割一覧](component-roles.md)を参照します。

### 線と操作部品

`--border-divider` は従来の薄い区切り色、`--border-control` は従来の検索入力の境界色、`--border-tool` は従来のtool境界色を受け持ちます。`--border` の互換aliasは撤去済みです。画像の下地や淡い操作背景は `--surface-muted` で所有します。線の色が似ていても、内容を区切る線と操作領域の境界は別の役割として編集します。色値はCSSだけに置きます。

通常の検索・入力・ボタン、内容の区切り、カードの囲み、写真上の前景、コード上の操作は背景と目的が異なります。角丸やfocusも全部品で機械的に同一化せず、役割一覧の対象と例外を確認します。共有操作の既存の大きな正方形領域（62px）は意図的な例外として維持し、一般ボタン寸法へ縮めません。

コードは明色ページ内の暗い面として [code.css](../../apps/site/src/styles/code.css) が所有し、構文色・コピーの成功/失敗・focusをその背景に合わせます。暗いコード面をサイト全体のdark themeと扱いません。ブランド、写真、ガラス材質も独自の表現を保持します。

### 独立toolとの境界

`Demo.astro` がサイト側トークンとtool公開CSS変数を接続します。固定版Prime v0.2.5ではdividerとcontrolが同じ `--bt-border` APIを使うため、内部まで分割できない例外を残します。固定vendorを手編集せず、API変更が必要なら独立tool sourceで変更し、正式releaseとinstallerで更新します。補足本文用の小さい文字とsummary操作文字は別の変数を使います。

## ホーム

正本は [index.astro](../../apps/site/src/pages/index.astro)、[home.css](../../apps/site/src/styles/home.css) と各ホーム部品です。

ヒーロー直下の「更新状況」は、記事・ツール・制作物・メモを通した最新の公開・更新1件を上段メタ情報・下段題名の2段で表示します。直下には記事・ツール・制作物・メモ全体の13週ストリップを置きます。公開catalogの公開・更新記録を使い、draft・noindex・heldを除きます。同日公開・更新は閲覧時刻に有効なイベントを選別してから1件にまとめます。アーカイブ済み制作物も公開された履歴は数えますが、制作物カルーセルからは除外します。架空のNews、build日時、Gitの編集時刻を更新の根拠にしません。

週はJST・月曜始まり、月曜の日付IDを使います。相対日数、13週の窓、72時間以内のNEWはブラウザ時計で計算し、復帰時と表示中の1分ごとに見直します。明示日時を優先し、日付のみはJST日の最早境界からでも72時間以内と確定する範囲だけNEWを表示します。不正・未来の明示日時を日付のみへ救済しません。実時刻を捏造・保存しません。JSなし・初回HTMLは絶対日付と未集計説明を示し、古いビルドの週別色やNEWを固定しません。

各マスはタップ不可で、数字を直接載せず、週別の代替テキスト・tooltipと全体件数を備えます。濃淡は0件・1件・2件・3件以上。操作・注目のaccentと同じRGBを透明度で段階化し、独立した灰紫のパレットを持ちません。公開前は一続きの点線、今週は読み上げ名を持つ三角で区別します。幅は本文端に揃えた最大520pxです。長期間更新がなくても隠さず、経過日数と空白週をそのまま表示します。公開ラベルは比較段階、段階2のリンク化・履歴ページ・絞り込みは未実装です。設計理由と記録の限界は[ADR-0072](adr/0072-home-update-activity.md)を参照します。

本文は更新状況、新着記事、制作物、ブラウザツールの順です。記事は公開日順です。カルーセルの動作は変更しません。

節見出しは本文と一覧リンクを同じ行に並べ、文字拡大で幅が足りない時はリンク全体を次行へ送ります。リンク内を折り返しません。「ブラウザツール」へ短縮し、ホーム見出しのモバイル縮小指定を外して元の共通サイズを使います。ツールは一列のリンク行です。囲み・角丸・別背景を持たず、複数項目の間だけdividerで区切ります。題名の直後に矢印を置き、行全体を単一リンクにします。題名は4種類共通の `.content-item-title` を使い、個別のサイズ・太さ指定を持ちません。末尾の余白を減らします。hoverとkeyboard focusで題名に下線を出し、focus ringも保持します。ホームの補助文字・日付・件数・数字は本文と同じ書体を使い、ブランドロゴと英語displayは独自の表現を保持します。ヒーロー下端には薄い暗幕を重ね、日本語キャッチを白で表示します。

ヒーローは工房写真、静的な `Think.` / `Build.` / `Run.` の3つのspan、日本語の短い説明で構成します。各spanをブロックとして並べ、旧仕様の「Think. Build.」と「Run.」の2行構成には戻しません。ヒーロー内にはリンクもボタンもありません。旧A/BのCTA配置や残存CSSを、現行DOMの導線と解釈しません。

写真は通常buildで固定された既存入力から派生画像を作り、既存の静的配信artifactへ含めます。実装の正本は [home-workshop-build.ts](../../apps/site/src/lib/home/home-workshop-build.ts) と `WorkshopPhoto.astro` です。写真のcrop・暗い重ね面・文字位置は一体で確認し、画像の寸法予約とLCP画像を遅延読み込みしない扱いを維持します。新規画像のGit追加やR2保存、公開受入れを意味しません。

制作物は `ProjectCarousel.astro` と `lib/home/project-carousel.ts` が所有します。JavaScript有効時は自動送り・循環、前後操作、ページ選択、停止/再開を備えます。狭幅では前後矢印を隠してページ選択とタッチ操作を使います。利用者による停止に加え、マウスhover、キーボードfocus、接触・ドラッグ、非表示タブ、viewport外などの条件で自動送りを止めます。reduced motionでは自動送りを止め、遷移もなくします。少数項目・空表示、複製スライドの読み上げとfocus除外、JavaScriptなしの標準スクロールを維持します。「自動再生しない」という旧説明は現行仕様ではありません。

記事カードはホームと記事一覧で共通部品を使います。画像あり/なしで領域を予約し、狭幅では画像を本文の上へ置きます。カード全体を単一リンクとし、長いタイトルを切り捨てません。公開catalogの抽出条件を変更して、保留記事で空きを埋めることはしません。

### Tailwind themeと共有役割

`global.css` の `@theme static` を色・内容題名の正本とします。`--brand-rgb` から操作色、静的ラベル、週別段階・点線・三角を派生させます。PROJECT・月/公開ラベルは静的文字、focusは操作accentへ接続します。ロゴSVGの材質色は変更しません。`--accent` と `--focus` は既存利用箇所をつなぐaliasで、別の色定義ではありません。

記事・制作物・ツール・更新の題名は `font-content` / `text-content-item` を `@apply` する単一の意味クラスを使用します。`home.css` は `@reference` でthemeを参照し、題名の位置・折返しだけを所有します。部品ごとのfont上書きや `!important` は加えません。共通h2のdisplay、本文、補助文字、ロゴは異なる役割です。

本人限定プレビューでも、ホームCSSだけでなく実HTMLがリンクする共有CSS・依存assetを一組で検査します。未リンクの新CSSが存在しても合格にしません。`home-style-contract.mjs` は欠落tokenを検出し、`home-design-webkit.mjs` は配布候補の実CSSを読み込んだcomputed style・画像・操作を検証します。後者はheadless WebKitであり実iPhone受入れとは区別します。

## 共通ヘッダーとナビゲーション

`BaseLayout.astro`、`global.css`、共通の `public/scripts/mobile-menu.js` がガラス面・前景色・メニュー表示と開閉を所有します。記事・検索・tool・固定ページにも同じ材質を使います。ホーム専用の `home.css` と `home-header.js` は写真上端への融合・固定配置・スクロール時の切替だけを上書きします。

モバイルメニューは中央揃えの一列です。native popoverとdetails fallbackを保ち、開閉中はガラス面とパネルを同期させます。リンクに別の遅延や二重のフェードを足しません。連続した開閉、Escape、領域外クリック、focus復帰、desktop幅への切替、reduced motionを検査します。文字拡大時はブランドが折り返せるようにし、ロゴと操作領域を縮めたり、ページ全体をoverflowで隠したりしません。ヘッダー下端と残りviewportに従ってメニューを配置します。

項目と順序の正本は [site-config.ts](../../apps/site/src/lib/site-config.ts) です。共通の7項目は「記事・メモ・教育資料・制作物・ツール・サイト紹介・問い合わせ」。検索は専用操作で、PCではGET検索フォーム、狭幅では検索ページへのリンクです。検索runtimeは `/search/` に限定し、ヘッダーへ検索JSを足しません。検索語はGETのURL・履歴に含まれるため、完全な非送信方式とは説明しません。

## フッター

`SiteFooter.astro` と `global.css` が所有します。上段の共通7項目とRSSを合わせた8導線は、一つのリストで中央揃えにし、折り返した各行も中央を維持します。均等割りの列や左揃えの行にはしません。リンク間の線は装飾として描き、文字として読み上げません。

下段は著作権、プライバシー、ソース改訂です。ソース改訂はビルド元コミットの日付とSHAであり、配信日時ではありません。取得できないローカルプレビューでは情報なしと表示し、仮の日付を作りません。上段の8導線と、下段の補助リンクを混同しません。
