# 素因数分解計算機の実UI速度比較（2026-11-10）

この記録はページの速度表示の根拠。全入力・端末・競合実装の順位ではない。
[測定値](prime-ui-20261110.json)は完了済み原本から入力・期待因子・24試行の計測値を抜粋したもの。計算途中の内部状態は含めず、原本SHA256を保持する。

## 結果

同じ総4 Worker枠で各入力ABBA順に2回ずつ、全24試行が因子照合・積の一致を満たして完了。表は中央値（秒）。

| bit | 計算機 | rusqsieve |
| --- | ---: | ---: |
| 192 | 1.447 | 1.030 |
| 216 | 3.917 | 4.130 |
| 224 | 5.958 | 6.471 |
| 232 | 11.272 | 12.711 |
| 240 | 13.629 | 15.829 |
| 256 | 39.119 | 47.157 |

216〜256bitの5入力はそれぞれ2回とも計算機が短く、192bitは2回ともrusqsieveが短い。各階層1入力・各2回の結果であり、統計的な優位性や他の入力・端末・ブラウザ・既定設定での順位を証明しない。

## 条件

- Core i7-9700K、WSL2（6論理CPU）、Headless Chromium 149、1280×900。各試行で新規browser process/profile。
- 実UIを操作し、準備完了後の開始クリックから因子がDOMへ出るまでを共通5ms間隔で検出。ダウンロード・初回読み込み・paint完了は含まない。
- 計算機は高精度・手動4 Worker・512MiB・300秒。実SIQS割当448MiB・4 slots。rusqsieveに人工的なメモリ制限は追加していない。
- rusqsieveは篩3＋集約1、計算機は篩4のうち1つが集約を兼任。各製品本来のWorker起動時期・前処理を保持。
- 計算機の内部制限300秒＋観測1秒猶予、比較相手の外部観測300秒。全試行300秒以内に成功し、timeout勝利はない。
- 192bitは既存比較の入力、216bit以上は上流固定corpusの各階層先頭1問。結果を見て入力を選び直していない。電源・熱・バックグラウンド負荷は固定していない。
- 計算機toolkit: `8d9e25771e538e2700a2d357929ceb398256170b`。サイトv0.2.5 provenanceのsrc70ファイルSHA256と一致を確認。
- rusqsieve 0.5.0: `4b150834b57636f6ebc350a81321a15c1cd901d2`、配布SIMD Wasm。
